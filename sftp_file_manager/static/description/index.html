SFTP File Manager

A WinSCP / FileZilla-style SFTP and FTP client inside Odoo

Define remote servers once, then browse folders and move files between your computer and the server — without leaving the browser.

Features

  • SFTP and FTP in one screen, chosen with a "File protocol" selector like WinSCP.
  • SFTP login with password or private key (RSA / Ed25519 / ECDSA, optional passphrase).
  • FTP login with password or anonymous, plain or with TLS/SSL explicit encryption.
  • File browser: breadcrumb navigation, folders first, size / date / permissions columns.
  • Download files (streamed, so large files are fine) and upload with a button or drag & drop.
  • New folder, rename and delete from the same screen.
  • Test Connection button on every server record.
  • SFTP host-key pinning (trust on first use): a changed server key is refused.
  • Two access groups: Users browse and transfer; Managers also edit connections and see credentials.

Installation

  1. Install the Python library in the virtualenv that runs Odoo: pip install paramiko
  2. Restart Odoo, update the Apps list and install SFTP File Manager.
  3. Open SFTP File Manager > Connections, create a server and press Test Connection.
  4. Open SFTP File Manager > File Browser and pick the server.

FTP uses Python's built-in ftplib; nothing extra is needed for it.

Good to know

  • All transfers pass through the Odoo server, so the Odoo server (not the user's PC) must be able to reach the remote host.
  • Plain FTP is unencrypted. Prefer SFTP, or FTP with TLS.
  • Passwords and private keys are stored as plain text in the database and are visible only to the Manager group.
  • Downloading whole folders and recursive operations are not supported.
