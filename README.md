# SFTP File Manager (Odoo 19)

WinSCP / FileZilla-style SFTP and FTP client for Odoo: manage server connections,
browse remote folders, upload and download files.

* Odoo version: 19.0 (branch `19.0`)
* License: LGPL-3
* Requires: `pip install paramiko`

See `docs/SFTP_File_Manager_User_Guide.pdf` for the user guide.
